# EMI 合成树使用与验证

首次使用请先看[左侧合成树操作手册](bookmark-user-guide.zh_cn.md)，包含建链、分组、调量、折叠、取料、自动合成及常见问题的逐步说明。

## 范围与实现原则

本功能面向 Minecraft 1.21.1 的 Fabric 与 NeoForge。它借鉴 NEI 合成树的交互与规划概念，在 EMI 的配方、材料和填充接口上独立重写；不是复用或套用旧补丁。界面及编译适配仍可能调整，具体控件和行为以最终 UI 为准。

合成树用于查看依赖、安排制作步骤和估算材料。它不负责机器自动化，也不提供 GT 旧版本耐久机制的专用桥接。工作站统计按 EMI 配方类别汇总执行批数，不代表并行机器台数、运行时间、能耗或自动化生产线。

## 左侧收藏合成链

GTNH NEI 截图中的绿色括号和逐行配方属于左侧书签栏。当前 EMI 已把这套入口接入原生左侧 FAVORITES 面板；下文独立画布是额外的规划视图。源码对照、差异和执行边界见 `nei-bookmark-sidebar.md`。

- 在配方或有配方上下文的结果槽上按 **Shift+A**（默认收藏键加 Shift）收藏完整默认子链，创建 TODO + 合成计算组。
- 括号左键切换紧凑／逐配方行；右键开关组内合成需求计算；**Alt+左键**折叠整组。在配方槽 Alt+左键折叠该依赖盒，整组已折叠时先展开。
- 括号左拖建立分组，右拖解除分组；**Shift+左拖**移动组或结果／配方盒。折叠盒对应的真实依赖一起移动。
- 槽或括号 **Ctrl+滚轮**调整数量；加 **Alt** 使用 `bookmarkQuantityStep` 配置步长（默认64，最小1）。整组折叠时调整所有根目标。默认看计算量、Shift看扣库存后的剩余量；合成计算组按住Ctrl调量时持续显示联动计算量，关闭计算时Ctrl看显式收藏量，Shift优先；提示同时列出三套值。同组兼容配方自动关联多候选输入，手动候选优先。
- 普通行与折叠盒输入均可用 **Shift+滚轮**选择具体材料并保存；行保留原始来源，所以即使当前材料相同，也不会合并后丢失候选编辑入口。所选输入用于模型和实际填充，插件原配方仍用于handler查找、类型及槽位判断。
- 拖动移出原槽／行或按住250ms启动；拖到侧栏上下边缘停留350ms可跨页继续。分组／移动以真实配方及折叠依赖anchor提交；跨页长按路径尚需专门实测，不能据普通拖动通过宣称全覆盖。
- 悬停组括号或结果，**T**打开只含本组所选配方／候选的临时树；它与全局 `BoM.tree`、当前保存计划和库存模式隔离，关闭回原界面。临时树禁用保存、删除、复制、导入和下一步，不是修改已存计划的入口。
- **V／Shift+V**从支持的普通9×1至9×6箱式容器取组基础材料及独立收藏，Shift扣除已有库存。仅物品，严格检查原版handler／槽位：EMI服务端协议精确移入空玩家槽并等源／目标raw ack；vanilla逐项PICKUP等槽／光标raw ack，预测不算完成，匹配预测不发包时可能100tick超时并尝试归还余量。不取中间物作为额外需求，不执行合成。EMI服务端精确取料已获真实世界PASS；vanilla无服务端EMI取料路径仍缺世界完成证据，完整边界见 `../tests/bookmark-transfer/README.md`。
- 悬停组括号或结果，**Shift+C**执行当前容器支持的整组制作；**Ctrl+Shift+C**扣除现有中间物，仅补缺。绑定可配置，运行中再次按键取消。只支持默认craft实现的标准handler、确定性且有明确消耗输入的可观察配方；每次精确一批，所有产物收到raw服务器确认后继续。foreign grid、自定义craft覆写、概率执行和机器自动化不支持；`status()`及侧栏提示区分接受、等待、完成与停止原因。

## 打开与阅读

1. 在 EMI 中选择配方，使用其配方树入口打开目标的合成树。
2. 中央画布显示目标与依赖；左侧显示保存的合成计划和名称输入框；右侧为统计。
3. 初始依赖沿用 EMI 的默认配方展开。没有合适默认配方的材料可手动指定；循环依赖会提示并停止继续展开。
4. 材料在同一计划的公用账本中汇总，库存与中间产物余量统一参与结算。多个分支依赖同一材料时，不能把每条视觉分支当作互相独立的材料清单。

右侧“切换分组”依次查看全部分组及单个分组：所需材料、库存已抵扣、制作步骤、材料已齐、目标产物、剩余产物、工作站批数。“库存已抵扣”表示账本中需求被库存覆盖的部分，不是整个背包物品清单。关闭库存时，“所需材料”显示未抵扣库存的需求；开启后显示尚缺材料。

带 `≈` 的金色材料数量是概率配方的期望估算，不是某次制作的保底产出，也不保证按期望次数一定获得目标。催化材料即便可重复使用，制作时仍需备齐。左收藏栏的组级 `Stock`／`Flow` 账本以同样的整批模型预算结算概率、共享库存、启动材料和容器返还，再投影普通行／折叠盒的内外边界；盒内相互抵消，跨盒物流保留，未用返还物列为余料。显式量使用收藏批数，不等于NEI全部独立影子盒重算规则；损坏工具动态替换及流体容器换算仍未实现。

为避免极深或过大的配方链拖垮客户端，展开最多128层、4096个节点。达到限制的截断节点显示橙色边框和截断提示；未展开分支按外部材料计入需求。此时上游配方与耗材并未完整展开，不能把该统计当作整条生产链的完整算量。

## 画布、节点与搜索

- 在画布滚动滚轮缩放；左键或中键拖动画布平移；“适应画布”重新容纳当前展开的图。
- 节点左键打开配方选择；在配方界面选择产物，可为当前树指定配方。原有 EMI 配方、用途及收藏快捷键仍可对悬停节点使用。
- `Shift + 左键` 根据当前物品栏尝试选择配方；非根节点 `Shift + 右键` 清除该节点的配方选择。
- 右键节点切换视觉折叠。顶部折叠按钮循环切换全部展开、折叠已满足、折叠非根分支。折叠只改变可见布局，不改变配方、需求或公用账本计算；根节点保留可见。
- 对含多个可选材料的节点，`Shift + 滚轮` 切换具体材料。
- 顶部按名称或资源 ID 搜索；`Ctrl + F` 聚焦搜索栏，`Enter` 定位下一个匹配，`Shift + Enter` 反向定位。定位会展开通往匹配节点的祖先路径。
- 统计材料行左键搜索并定位相应材料，右键打开其配方。
- 在底部批数栏滚动调整目标批数，也可在根节点上按 `Ctrl + 滚轮` 调整；加按 `Shift` 每次调整 16 批，最少为 1 批。

## 库存与填入一批

“库存：开”启用玩家物品栏快照抵扣，并在启用时采样。库存是手动快照：物品增减不会被描述成持续实时追踪。物品发生变化后使用“刷新库存”重新采样；切换计划等重新绑定当前树的操作也会建立快照。关闭库存后不再用快照抵扣需求。

“材料已齐”表示计划所用的库存快照足以覆盖该步骤的直接材料，不依赖当前机器或容器的 EMI 处理器；即使没有打开对应机器界面，也可以列入。“制作步骤”排除这些材料已齐的步骤。关闭库存快照后，不会读取实际背包来判定这两类分组。

“填入1批”另行使用当前容器的 EMI 配方处理器和实时材料检查，独立于上述快照分类。没有打开可用容器、处理器不支持配方或实际材料不够时，即使步骤列于“材料已齐”也不能填充；快照关闭时仍可通过实时检查执行填充。

“填入1批”查找一个当前容器能够处理的步骤，仅通过 EMI 填充接口填入 **1 批**配方材料。它不会自动取出产物或自动合成整棵树，也不会启动、控制或连续运行机器。用户仍需完成合成或机器加工，并在需要时手动刷新库存后继续。

## 保存、剪贴板与图片

- 在左侧名称栏输入名称后点“保存计划”，也可在名称栏按 `Enter`；`Ctrl + S` 可保存当前计划。左侧点击计划切换，“删除计划”删除当前已保存计划。达到计划上限时会提示。
- “复制JSON”把当前计划序列化为 JSON 写入系统剪贴板。“导入JSON”读取剪贴板中的计划 JSON；不是文件选择器，也不是图片识别。无效 JSON、不可用计划或超出上限时应给出失败提示。
- “导出图片”生成当前**完整可见布局**的 PNG，含画布视口外仍展开的节点，不受当前平移与缩放裁剪；已经折叠隐藏的子树不在图片中。统计开启时导出当前选择分组的全部统计行，不只导出侧栏滚动视口；统计关闭时不导出统计。
- 图片使用 EMI 截图倍率配置。分配图像存储前检查最终像素尺寸：任一边超过 **8192 像素**，或总像素超过 **16,777,216（16M）**即拒绝导出并提示。可折叠分支、关闭统计或降低截图倍率后重试；超大计划仍可继续编辑。

## 验证清单

以下是完整验收清单；已完成的检查与未覆盖范围另见下方“验证结果”，不能把清单本身当作全部通过。

1. **编译与加载**：分别按项目现有构建流程编译 1.21.1 Fabric 和 NeoForge，进入游戏后打开合成树，确认入口、容器返回和界面重开正常。
2. **语言覆盖**：在英文与简体中文间切换，检查全部按钮、窗口标题、提示与七种统计分组；库存开关及折叠三态都必须显示译文，不能露出 `emi.tree.*` 或 `screen.emi.recipe_tree`。
3. **JSON 静态检查**：将两份语言资源作为标准 JSON 解析；检查重复 key、空译文及格式占位符。提取最终新 UI 中的 `tr("...")` 与动作按钮列表，另显式展开 `inventory_on/off`、`fold_0/1/2` 及 `section.needed/available/crafting/ready/results/leftovers/machines`，逐项与两份语言文件比较。
4. **默认配方与公用账本**：选择含共享中间材料的配方，核对批数、基础材料及剩余产物；设置 EMI 默认配方或树内替代配方后检查依赖变化。特别检查同一种库存或余料没有在多个分支重复抵扣。
5. **折叠不改计算**：记录材料统计，分别右键折叠、循环顶部折叠状态、搜索隐藏节点；核对展开范围变化但账本数量不因视觉折叠改变。
6. **库存快照**：启用库存并记录尚缺，增减实际物品，确认快照不会悄然被当作实时库存；点击刷新后重新计算。核对“材料已齐”只按快照中的直接材料判定，在未打开对应机器时仍可出现，且不再重复列于“制作步骤”。关闭库存后恢复不抵扣库存的需求，并确认分组不读取实际背包判定。
7. **概率与催化材料**：用含概率消费或产出的配方检查 `≈` 期望提示，用可重复使用材料检查需求和提示；不要把期望值验收为单次保证值。
8. **下一步边界**：在兼容工作台及不兼容容器各测试“填入1批”，确认每次只填一批，未自动取出结果、连续合成或控制机器；无可填步骤时显示提示。
9. **计划与剪贴板**：保存、重命名、切换、删除计划；复制 JSON 后导入；用无效 JSON 验证失败提示。再次打开计划检查配方选择、批数、折叠与库存模式。
10. **完整布局图片与保护**：平移或放大到只看到一小片区域后导出，确认仍包含当前完整可见图及当前分组全部统计；再测试折叠和隐藏统计。构造超过单边 8192 或总计 16M 像素的导出，确认先提示拒绝且界面仍可编辑。
