# EMI 左侧合成树操作手册

适用版本：本项目修改版 EMI，Minecraft 1.20.1，Fabric / Forge。本文按当前实现编写，默认键位以未修改配置时为准。

这套功能位于 **EMI 左侧收藏栏**。先收藏目标配方及其依赖，再调整数量、查看材料、取料或执行当前工作台能处理的配方。

## 1. 第一次使用：从目标配方建立合成链

1. 打开背包或工作台，确认左侧显示 EMI 的“收藏 / FAVORITES”面板。
2. 在右侧物品列表搜索目标物品，把鼠标移到它上面，按 **R** 打开配方。
3. 找到想用的配方，将鼠标移到该配方的**结果物品槽**上，按 **Shift+A**。
4. 左侧会出现一个新组，默认开启逐配方行显示和合成需求计算。绿色括号标出这一组的范围。
5. 鼠标移到组内目标产物上，用 **Ctrl+滚轮**调整制作批数；移到左侧括号上可以调整整组目标。
6. 鼠标移到绿色括号或任一配方结果上，按 **T** 查看本组的树形图。

**Shift+A 应在有明确配方上下文的结果槽上使用。** 在右侧普通物品列表按 A，主要是收藏物品，不等于收藏整条合成链。

依赖展开使用 EMI 已选定的默认配方。有的中间材料没有默认配方时，会作为外部材料需求保留，不会凭空猜出全部制作步骤。

### 想指定另一种制作方法

在配方界面找到想用的制作方法，默认可对它的结果槽使用 **Ctrl+左键**设置 / 取消 EMI 默认配方，再收藏所需合成链。

已收藏组保留收藏时选中的配方。之后修改全局默认配方，不会自动把原组全部换成新路线。需要重建时，可先删除旧组，再在目标配方上按 Shift+A。

## 2. 先认清三个操作位置

| 位置 | 在哪里 | 用来做什么 |
| --- | --- | --- |
| 组括号 | 一组条目最左边的细竖线及上下短横线 | 切显示模式、开关计算、整组折叠、调整整组数量、执行组操作 |
| 配方结果槽 | 每个配方的产物图标；逐行模式中通常位于该配方行的开头 | 调整该配方批数、折叠依赖、打开树、启动组操作 |
| 材料槽 | 逐配方行中列出的输入材料 | 查看需求、切换可选材料；不作为 T / V / Shift+C 的组启动位置 |

- **绿色括号**：该组开启了合成需求计算。
- **灰色括号**：该组关闭了合成需求计算。
- **绿色槽框**：整组处于折叠状态。
- **紫色槽框**：某个配方及其依赖被折叠成一个盒。
- 尚未归入独立组的收藏属于“默认组”，可能没有单独括号。操作默认组时，使用左侧收藏栏顶部的**页码中区**，不要点左右翻页箭头。

普通悬停只显示物品本身的属性。**按住 Alt** 再悬停条目或组括号，才显示合成组操作提示、数量说明及最近一次合成 / 取料状态；松开 Alt 即恢复普通物品提示。

## 3. 显示模式与折叠

| 鼠标位置 | 操作 | 效果 |
| --- | --- | --- |
| 组括号 / 默认组页码中区 | 左键单击 | 在紧凑显示与逐配方行显示间切换 |
| 组括号 / 默认组页码中区 | 右键单击 | 开关组内合成需求计算，括号颜色随之变化 |
| 组括号 / 默认组页码中区 | Alt+左键 | 整组折叠 / 展开 |
| 开启计算的组内配方槽 | Alt+左键 | 折叠 / 展开该配方及其依赖 |
| 已整组折叠的槽 | Alt+左键 | 先展开整组 |

**视图、计算和折叠是不同开关。** 想看材料时，先切到逐配方行；数量看起来没有联动时，再检查是否关闭了组内合成计算。

折叠只减少显示内容，不会删掉依赖，也不会缩减自动合成的执行预算。

### 每一行怎么读

逐配方行的顺序为：**结果 → 余料（如有）→ 输入材料**。原料配方另起一行，因此第二行往往是中间物的制作方法，而不是第一行额外需要的一组材料。按住 Alt 悬停图标可看“产物 / 余料 / 材料”角色和三种数量。

例如“木板 4、原木 1”表示这一行的木板配方用 1 个原木产出 4 个木板。工作台行中重复的木板通常对应配方的不同输入槽：四格各 10 个表示制作 10 个工作台，共 40 个木板，不是四种必须分别准备的木材。

开启组内合成计算后，“任意木板”等多候选输入会自动关联同组兼容的制作配方。把工作台目标调到 10 个时，同组木板配方会联动为 40 个木板、10 个原木，无需先手动切换木种。若有多个兼容上游配方，按组内收藏顺序优先使用；Shift+滚轮手动指定的候选优先，且不会被自动关联覆盖。不同组之间不会借用上游配方。

旧版出现的无图标悬空“5”，以及“木板产物 0 + 假余料 4”，是空配方格和泛化材料流向分类错误，已在 2026年11月4日修正；不属于正常材料需求。

## 4. 数量怎么看、怎么调

### 三种数量

| 按键状态 | 图标旁显示的数量 | 含义 |
| --- | --- | --- |
| 不按修饰键 | 计算量 | 按整条链计算，未扣除背包库存 |
| 按住 Shift | 剩余量 | 扣除当前库存后仍需的数量 |
| 按住 Ctrl | 合成链显示计算量；关闭计算时显示显式量 | 调量时同组依赖保持联动显示；显式收藏批数仍可在悬停提示中查看 |
| 同时按 Shift 与 Ctrl | 剩余量 | Shift 优先 |

按住 Alt 的悬停提示会同时列出三种数量。大数会使用紧凑单位，详细值以提示为准。

### 调整数量

- **Ctrl+滚轮，悬停条目**：调整该收藏 / 配方的倍率。
- **Ctrl+滚轮，悬停组括号或默认组页码中区**：调整整组；合成链组主要调整根目标。
- **Ctrl+Alt+滚轮**：按较大步长调整，默认每次 64，可在 EMI 设置中修改。
- 整组折叠时，在其槽上调量也按整组处理。

滚轮调整的是**倍率 / 制作批数**，不一定是最终物品逐个加减。例如某配方一次产出 4 个物品，增加一批通常对应多生产 4 个。

### 选择材料变体

鼠标放到有多个候选的**输入材料槽**上，按住 **Shift**滚动滚轮，可切换具体材料，例如从橡木切换到白桦木。

选择会保存，并用于后续计算和实际填充。若该材料本身有上游制作配方，切换候选不会自动替你重建整条上游路线；应检查上游配方是否仍匹配。

## 5. 建组、解组与排序

| 操作位置 | 操作 | 效果 |
| --- | --- | --- |
| 左侧组操作带，也就是括号所在的窄区域 | 左键按住并跨行拖动 | 将覆盖条目建立为新组 |
| 同一区域 | 右键按住并跨行拖动 | 解除覆盖条目的分组，放回默认组 |
| 已有组括号 | Shift+左键拖到另一组 | 调整整组顺序 |
| 结果 / 独立收藏槽 | Shift+左键拖动 | 排序条目；配方和折叠依赖会按整体移动 |

**移动已有合成组**：按住 Shift，在组括号上按住左键即可抓起整组，出现跟随鼠标的组预览。向上拖到目标组的第一行时，实时插到它前面；向下拖到目标组的最后一行时，实时插到它后面。移到目标组中间不会把它拆开。松开左键结束移动，组内顺序、数量、候选、折叠状态均保留。

其它条目排序 / 建组拖动在移出原槽 / 原行，或按住约 250ms 后启动。拖到侧栏上下边缘停留约 350ms，可触发跨页拖动；该长按跨页路径尚未专门完成实机验证。

材料槽不能当成独立结果随意拖散。分组和移动会保留整配方或折叠子链边界。

## 6. T：查看本组树形图

鼠标放在**组括号、默认组页码中区或配方结果**上，按 **T**。

这是当前组的临时只读树，展示本组已经选中的配方和材料候选，不会覆盖已有保存计划，也不会另行按全局默认配方扩展整棵树。

常用操作：

- 滚轮：缩放。
- 左键 / 中键拖动画布：平移。
- 右键节点：折叠 / 展开分支。
- 顶部搜索框：按名称或资源 ID 搜索；**Ctrl+F**聚焦搜索。
- **Enter / Shift+Enter**：定位下一个 / 上一个搜索结果。
- “适应画布”：重新把当前图放进视口。
- 库存开关 / 刷新：查看按库存快照抵扣后的需求；物品变化后手动刷新。
- **Esc**：若搜索框等输入框正有焦点，先退出输入；再次按下关闭，返回原界面。

临时组树禁用保存、删除、复制、导入和“填入下一步”等编辑 / 执行功能。要改组内数量或材料候选，请回到左侧收藏栏操作。

## 7. V：从箱子取材料

### 操作步骤

1. 打开普通箱式存储界面，例如原版箱子。
2. 确保鼠标光标上没有拿着物品，背包留有空位。
3. 将鼠标移到要取料的**组括号或配方结果**上。
4. 按 **V**：按组预算取基础材料。
5. 按 **Shift+V**：先扣除玩家背包已有材料，再取缺少部分。
6. 等待状态完成。运行中再次按取料键，会请求取消。

V 读取组内配方推导的基础材料需求；组内独立物品收藏也可作为取料需求。它**不会执行配方**，不会把合成链中每种中间产物都额外取一份。

### 支持范围

- 仅支持使用原版通用箱式处理器的 9×1 至 9×6 存储界面及普通槽位。
- 仅支持物品。流体、特殊机器、特殊槽位不在当前支持范围。
- 服务端安装兼容 EMI 时，使用现有服务端填充协议精确取料，需要**空玩家背包槽**；不能只靠已有同类物品的未满堆叠空间。
- 无服务端 EMI 时使用逐项点击并等待真实确认；原版可能不发送与预测一致的确认包，此时会超时停止，当前不能保证所有这类环境均能完成取料。

实际测试已确认：箱中 64 个圆石，只请求 3 个，最终箱内 61、玩家背包 3、光标为空。

取料期间请保持当前容器打开，避免同时手动移动相关物品。若取消或超时后提示光标仍有余量，请先检查并手动放回，再启动下一次操作。不要把“已接受”或“等待确认”当成完成。

## 8. Shift+C：在当前工作台执行整组制作

### 操作步骤

1. 先准备材料，可手动拿取或使用上一节的取料功能。
2. 打开能处理这些配方的工作台。含 3×3 配方的链，需要打开工作台，不能只开玩家 2×2 背包合成栏。
3. 保持光标为空，背包留有产物和返还物空间。首次尝试建议先清空合成网格。
4. 鼠标放到**组括号或配方结果**上，按 **Shift+C**。
5. 等待完成，运行中再次按组合成键可取消。

| 按键 | 执行方式 |
| --- | --- |
| Shift+C | 按请求预算制作，不用已有中间物抵消生产预算；仍需备足材料 |
| Ctrl+Shift+C | 扣除已有物品 / 中间物，只制作尚缺部分 |

**即使鼠标悬停某个结果，启动的也是它所属组的任务。** 若只想做一个配方，可把它单独分组，或使用 EMI 原有的单配方填充操作。

执行器每次精确制作一批，等实际服务端库存确认产物后再继续。它不会自动打开工作台、切换机器或在机器间运输材料。

### 可能停止的情况

- 当前界面没有兼容的配方处理器，或配方需要另一种工作台 / 机器。
- 缺材料、产物空间不足，或合成网格含有无关物品。
- 插件使用自定义合成逻辑；配方输出带概率，或没有明确消耗输入。
- 服务端长时间没有确认、库存变化与预期不符，或运行中切换界面。

取料和合成互斥。取料尚在归还光标 / 等待取消时，按合成键会先请求安全取消取料；等取料结束后，需要**再按一次合成键**。

## 9. 删除与取消

| 鼠标位置 | 操作 | 效果 |
| --- | --- | --- |
| 展开状态的收藏条目 | A | 删除对应收藏；配方材料投影对应其原始收藏 |
| 折叠整组 / 折叠子链槽 | A | 保留，不直接删除隐藏内容 |
| 折叠整组 / 折叠子链槽 | Shift+A | 删除该槽代表的组 / 依赖子链 |
| 组括号 / 默认组页码中区 | Shift+A | 删除整组收藏 |
| 运行中的组任务 | 再按 V 或组合成键 | 取消对应取料 / 合成任务 |

**右拖解组只改变归属；Shift+A 删除会移除收藏。** 删收藏不会删除背包里的实际物品。

分组、倍率、所选材料及显示状态会随收藏数据保存；运行中的取料 / 合成任务不会作为持久任务保存。

## 10. 一个推荐的完整流程

以原木 → 木板 → 箱子为例：

1. 搜索箱子，按 R 找到想用的箱子配方。
2. 确认木板已有合适的 EMI 默认制作配方，再在箱子结果槽上按 Shift+A。
3. 左侧出现箱子及木板依赖组；检查是否已经包含木板配方。若没有，上游木板会按外部材料需求处理。
4. 对箱子结果 Ctrl+滚轮调批数，保持逐配方行模式核对原料。
5. 如要指定木种，在相应输入槽 Shift+滚轮切换，并核对依赖配方一致。
6. 按 T 检查组树，退出后打开存放原料的箱子，悬停组括号按 Shift+V 取缺料。
7. 等取料结束，打开工作台，悬停同组按 Ctrl+Shift+C 补缺制作。
8. 查看组提示，确认任务已经完成；按住 Shift 可查看剩余量。

如果只想算材料或保留制作清单，做到第 5 步即可，无需启动自动合成。

## 11. 找不到功能或按键没反应

| 现象 | 检查与处理 |
| --- | --- |
| 左侧没有收藏栏 | 打开 EMI 设置，检查左侧侧栏页面是否包含“收藏 / FAVORITES”，并切到该页面；界面太窄时检查侧栏尺寸和 GUI 缩放 |
| 首次打开物品栏等待 | 四套界面缓冲现在在主菜单首次显示前准备，首次开栏复用；关闭 EMI 时跳过，之后启用仍有进入世界后的分 tick 准备。无须手动触发。进入世界时，等服务器配方和标签都同步、世界与玩家就绪后，EMI 会在客户端 tick 自动启动索引构建，无须打开物品栏；可在日志看到“Initializing EMI on world entry”。这不会让主菜单拥有世界相关索引，也不缩短插件索引构建和首次 GPU 图标上传的实际耗时 |
| Shift+A 只得到一个物品 | 打开具体配方，把鼠标放在结果槽上再按；普通物品列表没有明确配方上下文 |
| 链缺少上游步骤 | 为中间物选好 EMI 默认配方，再重建所需收藏链 |
| T / V / Shift+C 无反应 | 鼠标放到组括号或结果槽，避开输入材料槽；退出搜索框输入，检查按键冲突 |
| 数量和预想不同 | 分清批数与件数；检查 Shift / Ctrl 显示模式、组计算开关、候选材料和配方单批产量 |
| V 提示背包已满 | 服务端精确路径需要空槽；合并现有堆叠后留出空位再试 |
| V 提示容器不支持 | 改用普通箱式存储界面；外观像箱子的模组容器也可能使用特殊处理器而不支持 |
| 合成拒绝填入 | 检查工作台尺寸、直接材料、合成网格、输出空间；特殊机器和自定义 handler 可能不支持 |
| 一直等待服务器 | 查看组提示中的状态；约 100 个玩家 tick 未确认会超时，服务端卡顿时现实等待更长 |
| 取消后不能立刻开始合成 | 先等取料安全停止 / 归还光标，再按一次合成键 |

EMI 设置中可修改以下项目：

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `binds.favorite` | A | 收藏；在配方上下文额外加 Shift 建链 |
| `binds.view-bookmark-group` | T | 打开临时组树 |
| `binds.take-bookmark-group` | V | 取料；额外加 Shift 仅取缺料 |
| `binds.craft-bookmark-group` | Shift+C | 执行整组；额外加 Ctrl 补缺 |
| `ui.bookmark-quantity-step` | 64 | Ctrl+Alt+滚轮的数量步长，最小为 1 |

改键后，按设置中的实际绑定操作；“额外加 Shift / Ctrl”的功能仍按相应修饰键触发。

## 12. 当前边界与更多资料

- 动态耐久工具替换、流体容器换算、聊天配方链接和完整 NEI 数量弹窗尚未移植。
- 概率配方可以参与材料期望量估算，不代表自动合成会执行，也不是保底产量。
- 机器自动化、跨机器调度不在本功能范围内。
- 已验证 Fabric 真实界面与整合服务器，Fabric / Forge 均已构建；独立远程服务器、Forge 游戏内运行和各种模组机器未全面验证。
- EMI 服务端取料复用既有协议；多人同时改动源箱 / 目标槽可能导致结果偏离预期，应避免同时操作同一批物品。

本手册侧重日常操作。保存计划、独立可编辑画布、导出图片等功能见[合成树使用与验证](crafting-tree.md)；源码对照及详细实现差异见[NEI 左侧合成链对照](nei-bookmark-sidebar.md)。
